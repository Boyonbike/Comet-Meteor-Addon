# Call to Arms

[Documentation index](../README.md) · [Project README](../../README.md)

Module: **call-to-arms**.

Bind **call-to-arms** to a key to prepare a one-shot Discord rally message, then let it switch itself off. Configure its webhook, ping, call-to-action and optional contents. **show-coordinates** starts off; enabling it requires confirmation with the exact coordinates. Screenshots and other contents can still reveal location.

See [Discord reports and webhooks](../guides/discord-webhooks.md) for setup, cooldowns, confirmation, screenshot behaviour and shared contents settings.
