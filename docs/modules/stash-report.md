# Stash Report

[Documentation index](../README.md) · [Project README](../../README.md)

Module: **stash-report**.

Bind **stash-report** to a key to report loaded storage to the clan stash bot. Configure its webhook and required **discord-user-id**. It never includes coordinates or pings anyone; keep **show-screenshot** enabled if the receiving bot requires an image.

See [Discord reports and webhooks](../guides/discord-webhooks.md) for setup, cooldowns, confirmation, screenshot behaviour and shared contents settings.
