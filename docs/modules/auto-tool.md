# Auto Tool

[Documentation index](../README.md) · [Project README](../../README.md)

Module: **auto-tool** (Meteor upgrade; the original and Comet entries share state).

Comet extends Meteor Auto Tool with main-inventory selection. Enable **use-inventory** to include the 27 main-inventory slots while retaining the normal enchantment preferences, lists, anti-break, delay and switch-back settings.

See [inventory loans](../guides/inventory-loans.md) for transfer/restoration rules, shared-loan coordination and server limitations.
