# Licence and credits

[Documentation index](../README.md) · [Project README](../../README.md)

Much of Comet is possible because of the work shared by open-source developers.
Credit for upstream modules, algorithms and ideas belongs to their original authors
and contributors. Comet adapts, integrates and tunes that work alongside its own code;
please recognise and support the upstream projects credited below.

Original Comet code is released under **CC0 1.0** (`LICENSE-CC0`). The repository
as a whole, and every JAR and source archive, is distributed under
**GPL-3.0-only** (`LICENSE`, version 3 only) because it combines that code with GPL-3.0-only
adaptations of THM Addons, DEVILS and Quiettee Utils (Boat Fly), an Apache-2.0
adaptation of NoTextureRotations (`LICENSE-NoTextureRotations`), and Majkey's
DubCounter (included with permission). Chat Tools bundles the Inter typeface
(SIL OFL 1.1, `LICENSE-Inter`) and a subset of the Lucide icon font (ISC,
`LICENSE-Lucide`). VolytraFly's CC0 boost curve is credited in the code
and in [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md), which lists every
component, its source revision and the files it covers, including the optional
Meteor, Baritone and Xaero integrations.

If you redistribute Comet, ship the matching
`build/distributions/comet-<version>-mc26.2-source.zip` with the JAR, as
GPL-3.0-only requires. The JAR bundles `LICENSE`, `LICENSE-CC0`,
`LICENSE-NoTextureRotations`, `LICENSE-Inter`, `LICENSE-Lucide` and
`THIRD_PARTY_NOTICES.md`.
